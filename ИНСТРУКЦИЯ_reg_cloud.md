# Пошаговая инструкция: задание на reg.cloud (VPS)

Это шпаргалка к «Заданию до субботы». Идём строго по шагам, в каждом шаге написано,
что нажать на сайте и что ввести в терминале.

---

## ШАГ 1. Регистрация на reg.ru / reg.cloud

1. Открой https://www.reg.ru (или https://reg.cloud).
2. Нажми **«Регистрация»** (правый верхний угол).
3. Введи e-mail и придумай пароль → подтверди почту по ссылке из письма.
4. Зайди в личный кабинет, заполни профиль (ФИО) — без этого могут не дать оплатить услуги.

## ШАГ 2. Пополнить баланс

1. В личном кабинете: **«Финансы» → «Пополнить баланс»**.
2. Любая сумма от ~300–500 ₽ (на минимальный тариф хватит на месяц с запасом).
3. Оплата картой. Баланс обновится сразу.

## ШАГ 3. Заказать VPS (сервер)

1. В меню сайта: **«Хостинг» → «Облачные серверы» (VDS/VPS)** или прямая ссылка https://www.reg.ru/cloud-server/.
2. Нажми **«Заказать» / «Создать сервер»**.
3. Выбери параметры (важно только это):
   - **Локация:** любой в России (например, Москва).
   - **Тариф:** самый дешёвый (1 vCPU, 1 ГБ RAM — для задания хватит; можно взять 2 ГБ).
   - **Операционная система:** **Ubuntu 22.04 LTS** (или Ubuntu 24.04).
   - **Управление:** «самостоятельное управление» (без панели).
4. Придумай **root-пароль** (запиши его! он понадобится в ШАГЕ 6).
5. Оплати (списать с баланса), подожди 5–15 минут — сервер создастся.

## ШАГ 4. Узнать IP сервера и проверить доступ

1. В личном кабинете: **«Мои услуги» → «Облачные серверы»**.
2. Рядом с сервером будет **IP-адрес** вида `31.xxx.xxx.xxx` — **запиши его**, он нужен везде дальше.
3. Проверь, что сервер живой: открой в браузере `http://ТВОЙ_IP` — должна быть заглушка или пустая страница (значит работает).

## ШАГ 5. Подготовить проект у себя на компьютере

Перед заходом на сервер надо собрать и залить Docker-образы. Для этого на свой компьютер
нужно установить **Docker Desktop**: https://www.docker.com/products/docker-desktop/

1. Склонируй репозиторий с кодом:
   ```bash
   git clone https://github.com/Godlike-Bagheera/DZ.git
   cd DZ
   ```
2. **Вставь реальный IP** вместо заглушки: открой файл `frontend/src/App.jsx`,
   найди `IP_СЕРВЕРА` и замени на IP из ШАГА 4 (сохрани файл).
3. Зарегистрируйся на https://hub.docker.com (если ещё нет аккаунта) — логин должен совпадать
   с именем в docker-compose.yml (`Godlike-Bagheera`) либо поменяй имена образов под свой логин.
4. Собери и залей образы (команды выполняются в папке проекта, Docker Desktop должен быть запущен):
   ```bash
   docker login                      # логин и пароль от Docker Hub
   docker build -t Godlike-Bagheera/backend-image ./backend
   docker build -t Godlike-Bagheera/frontend-image ./frontend
   docker push Godlike-Bagheera/backend-image
   docker push Godlike-Bagheera/frontend-image
   ```
   ✅ Скриншоты этих команд — для отчёта преподавателю (обычно просят).

## ШАГ 6. Подключиться к серверу по SSH

**Windows:** установи PuTTY (https://www.putty.org/) или используй встроенный PowerShell:
```powershell
ssh root@ТВОЙ_IP
```
**Mac/Linux:** просто та же команда в терминале.

При первом подключении напишет «Are you sure? (yes/no)» → введи `yes`, затем root-пароль из ШАГА 3
(при вводе пароля символы не отображаются — это нормально).

## ШАГ 7. Установить Docker на сервере

Вставляй команды по одной прямо в SSH-терминал:
```bash
apt update
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
docker --version        # проверка: должна показаться версия
```

## ШАГ 8. Создать docker-compose.yml на сервере и запустить приложение

```bash
mkdir -p /root/myapp && cd /root/myapp
nano docker-compose.yml
```
В nano: правая кнопка мыши → Paste (вставить содержимое файла docker-compose.yml из репозитория),
сохранить: **Ctrl+O → Enter**, выйти: **Ctrl+X**.

Содержимое, которое надо вставить (можно скопировать с GitHub):
```yaml
services:
  backend:
    image: Godlike-Bagheera/backend-image
    restart: always
    ports:
      - "8000:8000"
  frontend:
    image: Godlike-Bagheera/frontend-image
    restart: always
    ports:
      - "80:80"
```

Запуск:
```bash
docker compose up -d
docker compose ps          # оба сервиса должны быть State: running
```

## ШАГ 9. Проверка результата (главный скриншот!)

Открой в браузере:
- `http://ТВОЙ_IP` — должен появиться интерфейс React с кнопкой, которая показывает ответ
  Django («Привет с Django!»).
- `http://ТВОЙ_IP:8000/api/hello/` — JSON напрямую.

Если не открывается — скорее всего закрыты порты:
```bash
ufw disable     # или разреши порты: ufw allow 80, 8000
```
Также проверь, что в личном кабинете reg.cloud для сервера нет включённого файрвола/групп
 безопасности, блокирующих порты 80 и 8000.

## ШАГ 10. Отчёт преподавателю

Собери скриншоты:
1. Сервер в личном кабинете reg.cloud с IP.
2. Команды сборки и пуша образов (ШАГ 5).
3. `docker compose ps` с running-контейнерами (ШАГ 8).
4. Работающий сайт в браузере по IP (ШАГ 9).

### Частые проблемы
| Проблема | Решение |
|---|---|
| `ssh: connection refused / timeout` | Подожди 10–15 мин после создания сервера; проверь IP; перезагрузи сервер в кабинете |
| `permission denied` при `docker push` | Имя образа должно начинаться с твоего логина Docker Hub; сделай `docker login`; поменяй имена в compose-файле |
| Порт 80 занят | `ss -tlnp \| grep :80` — останови мешающее (`systemctl stop nginx/apache2`) |
| Кнопка на сайте не отвечает | Не заменил IP в App.jsx / не пересобрал фронтенд-образ; CORS уже настроен в бэкенде |
| `docker compose: command not found` | На старых системах: `docker-compose` через дефис, либо доустанови плагин compose |
