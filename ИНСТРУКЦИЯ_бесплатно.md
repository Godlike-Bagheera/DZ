# Пошаговая инструкция: задание бесплатно, без VPS и reg.cloud

Всё делаем на своём ПК. Нужны только: Docker Desktop (бесплатно), GitHub, Docker Hub (бесплатный аккаунт).

## ШАГ 1. Установи Docker Desktop
1. Скачай: https://www.docker.com/products/docker-desktop/ (Windows или Mac — бесплатно).
2. Установи, запусти, подожди зелёного статуса «Docker Desktop is running».

## ШАГ 2. Скачай проект
Открой терминал (Windows: PowerShell; Mac/Linux: Terminal) и выполни:
```bash
git clone https://github.com/k1ttt3n/dz.git
cd DZ
```

## ШАГ 3. Запусти всё одной командой
```bash
docker compose up -d --build
```
Появится вывод сборки двух образов — это нормально, займёт 2–5 минут.

📸 СКРИНШОТ №1: вывод `docker compose up -d --build` в терминале.

## ШАГ 4. Проверь в браузере
1. Открой **http://localhost** → страница «React фронтенд» с текстом **«Привет с Django!»**
   📸 СКРИНШОТ №2: эта страница.
2. Открой **http://localhost:8000/api/hello/** → JSON `{"message": "Привет с Django!"}`
   📸 СКРИНШОТ №3: этот JSON.
3. В терминале: `docker compose ps` → оба сервиса `Up`.
   📸 СКРИНШОТ №4: вывод `docker compose ps`.

## ШАГ 5. Залей образы на Docker Hub (по желанию задания)
1. Если ещё нет аккаунта: зарегистрируйся на https://hub.docker.com (email `твоя_почта@gmail.com`). ВАЖНО: для входа/пуша нужен **логин (username)**, не email — посмотри его в профиле (предположительно `k1ttt3n`).
2. Создай Access Token: hub.docker.com → Settings (аватар) → Security → New Access Token → Read, Write → Generate. Скопируй токен.
3. В терминале из папки проекта:
```bash
docker login -u ТВОЙ_ЛОГИН        # введи токен вместо пароля
docker compose build
docker compose push
```
📸 СКРИНШОТ №5: два репозитория образа на hub.docker.com.

⚠️ Если пуш пишет `denied: requested access...`: имя образа должно начинаться с твоего логина Docker Hub. Открой `docker-compose.yml` и замени `k1ttt3n` на свой логин в обеих строках `image:`.

## ШАГ 6. Публичная ссылка (если преподаватель требует «сайт в интернете»)
```bash
npx localtunnel --port 80
```
(нужен Node.js). Даст бесплатный адрес `https://случайное-имя.loca.lt` — работает, пока включён ПК.
📸 СКРИНШОТ №6: открытый сайт по этой ссылке.

## Готово
Сдай скриншоты №1–4 (минимум) + ссылки на GitHub-репозиторий. Код уже лежит в https://github.com/k1ttt3n/dz.

## Частые проблемы
| Проблема | Решение |
|---|---|
| `docker: command not found` | Docker Desktop не запущен |
| Порт 80 занят | В docker-compose.yml замени `"80:80"` на `"8080:80"`, открывай http://localhost:8080 |
| На странице «Ошибка: ...» | Подожди 5–10 сек и обнови; проверь `docker compose logs backend` |
| Нет git | Ставь с https://git-scm.com или скачай проект кнопкой Code → Download ZIP |
