# Бесплатное выполнение задания (без VPS и без reg.cloud)

Всё задание делается **полностью бесплатно** на твоём ноутбуке: Docker Desktop + GitHub + Docker Hub — все тарифы бесплатные. Платный VPS не нужен.

## Что уже настроено в проекте
- `frontend/src/App.jsx` ходит на **относительный** адрес `/api/hello/` — больше **не нужно вставлять IP сервера никуда**.
- `frontend/nginx.conf` проксирует `/api/` на контейнер бэкенда (`http://backend:8000`).
- `docker-compose.yml` собирает и запускает оба контейнера одной командой.
- `deploy.sh` — скрипт-помощник (`./deploy.sh local` или `./deploy.sh push`).

---

## Вариант 1. Просто запустить всё локально (для скриншотов преподавателю)

1. Установи **Docker Desktop**: https://www.docker.com/products/docker-desktop/ (бесплатно). Запусти его.
2. Открой папку проекта в терминале (Windows: PowerShell, Mac/Linux: Terminal):
   ```bash
   git clone https://github.com/Godlike-Bagheera/DZ.git
   cd DZ
   docker compose up -d --build
   ```
3. Открой в браузере **http://localhost** — появится React-страница с надписью «Привет с Django!».
4. Проверь API напрямую: **http://localhost:8000/api/hello/**
5. Остановить: `docker compose down`

📸 Скриншоты для отчёта: вывод `docker compose up`, страница http://localhost, JSON по /api/hello/, вывод `docker compose ps`.

## Вариант 2. Залить образы на Docker Hub (тоже бесплатно)

1. Зарегистрируйся на https://hub.docker.com (бесплатный аккаунт). Твои данные: логин `testbagheera666@gmail.com`.
   ⚠️ Для пуша может потребоваться **Access Token**: Docker Hub → Settings → Security → Access Tokens → Generate.
2. В проекте выполни:
   ```bash
   docker login -u ТВОЙ_ЛОГИН_DOCKERHUB
   ./deploy.sh push
   ```
   (или вручную `docker build` + `docker push` — команды внутри deploy.sh)

✅ Скриншот: залитые репозитории `Godlike-Bagheera/backend-image` и `Godlike-Bagheera/frontend-image` на hub.docker.com.

## Вариант 3. Если преподаватель требует именно публичный адрес (бесплатно)

Без VPS можно выдать локальный сайт в интернет временной ссылкой:
```bash
# после docker compose up -d
npx localtunnel --port 80
```
Откроется бесплатный адрес вида `https://имя.loca.lt` — им можно поделиться и сделать скриншот. Работает, пока запущен твой компьютер.

## Частые проблемы
| Проблема | Решение |
|---|---|
| `docker: command not found` | Не установлен/не запущен Docker Desktop |
| Порт 80 занят другим приложением | В `docker-compose.yml` поменяй `"80:80"` на `"8080:80"` и открывай http://localhost:8080 |
| `denied: requested access...` при push | Имя образа должно начинаться с твоего логина Docker Hub; замени `Godlike-Bagheera` на свой логин в docker-compose.yml и командах |
| Страница грузится, но «Ошибка» в тексте | Подожди 5–10 сек (бэкенд стартует) и обнови; проверь `docker compose logs backend` |
