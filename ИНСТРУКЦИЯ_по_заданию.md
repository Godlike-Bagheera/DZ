# Выполнение задания по шагам (Docker Hub + GitHub Codespaces вместо платного VPS)

Задание требует: собрать Docker-образы, залить на Docker Hub, запустить на сервере и получить рабочий сайт.
VPS покупать НЕ нужно — его бесплатно заменяет GitHub Codespaces (виртуальная машина в браузере с Docker).

## ШАГ 1. Регистрация на Docker Hub
1. Открой https://hub.docker.com
2. Нажми **Sign Up** → email: testbagheera666@gmail.com, придумай username (например `testbagheera666`), пароль.
3. Подтверди email из письма.
📸 СКРИНШОТ 1: главная Docker Hub, ты залогинен (виден ник справа вверху).

## ШАГ 2. Сборка и заливка образов
Всё это делается в терминале (PowerShell на Windows илиCodespaces). Команды:

```bash
docker login          # введи username и пароль от Docker Hub
```
📸 СКРИНШОТ 2: надпись **Login Succeeded**.

```bash
docker build -t testbagheera666/backend-image ./backend
docker build -t testbagheera666/frontend-image ./frontend
docker images
```
📸 СКРИНШОТ 3: вывод `docker images` с двумя образами.

```bash
docker push testbagheera666/backend-image
docker push testbagheera666/frontend-image
```
📸 СКРИНШОТ 4: надписи Pushed и digest.

Открой https://hub.docker.com → Repositories
📸 СКРИНШОТ 5: твои два репозитория.

## ШАГ 3–4. «Бесплатный сервер» вместо reg.cloud = GitHub Codespaces
1. Открой https://github.com/Godlike-Bagheera/DZ
2. Нажми зелёную кнопку **<> Code** → **Codespaces** → **+ Create codespace on main**.
3. Подожди 1–2 минуты — откроется VS Code прямо в браузере. Это и есть твой сервер.
📸 СКРИНШОТ 6: открывшийся codespace (видно редактор и терминал).

В терминале codespace:
```bash
git clone https://github.com/Godlike-Bagheera/DZ.git  # если кода нет
```
📸 СКРИНШОТ 7: приглашение вида `codespaces@...` (аналог root@сервер из задания).

## ШАГ 5. Docker уже установлен в Codespaces
Проверь:
```bash
docker --version
```
📸 СКРИНШОТ 8: версия Docker.

## ШАГ 6. docker-compose.yml
Файл уже лежит в корне проекта (ник заменён на твой). Проверь:
```bash
cat docker-compose.yml
```
📸 СКРИНШОТ 9: содержимое файла.

## ШАГ 7. Запуск контейнеров
```bash
docker compose pull
docker compose up -d
docker compose ps
```
📸 СКРИНШОТ 10: оба контейнера в статусе **Up**.

## ШАГ 8. Порты
В Codespaces порты открывать не нужно — они пробрасываются автоматически.
Внизу терминала открой вкладку **PORTS** → найди порт 80 → нажми на адрес вида
`https://xxxx-80.github.dev`.
📸 СКРИНШОТ 11: вкладка PORTS с двумя портами (80 и 8000).

## ШАГ 9. IP менять не нужно
В нашем коде фронтенд обращается к API через относительный путь `/api/hello/`,
nginx проксирует его на бэкенд. Работает по любому адресу без пересборки.
(Это улучшение против задания — там требовалось руками вписывать IP.)

## ШАГ 10. Проверка
Открой ссылку из вкладки PORTS (порт 80).
Должна открыться страница React с надписью **«Привет с Django!»**
📸 СКРИНШОТ 12: браузер с работающим сайтом.
